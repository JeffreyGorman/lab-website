Team photos go here, named  photo_<INITIALS>.jpg  (e.g. Jeffrey Gorman -> photo_JG.jpg).
Square-ish JPEG, about 600 px wide.  See UPDATING.md for a one-line resize command.

The initials must match the "initials" field for that person in data/team.js.
That file is the only other place to touch: add one entry (name, initials, title, role, bio)
and the person appears in the "Meet the Team" grid on the homepage; clicking their photo opens their bio.

If a photo is missing (or the entry says  photo: false ), the default avatar is shown instead.
